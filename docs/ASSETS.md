# Frostpunk web assets

Generated by `tools/optimize_assets.py` (run with `python -I tools/optimize_assets.py`). Do not edit the outputs by hand.

- Output: `apps/web/public/assets/` (`manifest.json` plus `cards/`, `tokens/`, `tiles/`, `boards/`, `models/`, `audio/`, `pdf/`)
- Typed accessors: `apps/web/src/assets/manifest.ts`
- Cache: `tools/.optimize_cache.json`, keyed by sha1 of source bytes, parameters and VERSION. A rerun with no source changes takes about 36 s and reuses cached outputs. Delete the cache to force a full rebuild.
- Stale files in the category directories are pruned on each run.

## Manifest keys for the UI

Use the accessors, not raw paths. Each returns `undefined` for an unknown key.

| Accessor | Key | Returns |
|---|---|---|
| `cardUrl(id)` | card id, e.g. `M001`, `D000`, `L01A`, `SD01`, `X12`, `W03`, `S1N`, `ADV_HEALTH` | face image URL |
| `cardBackUrl(id)` | unique-back card id (`<id>_back`, e.g. `S01_back`) or family key `back_morning`, `back_dusk`, `back_near`, `back_far`, `back_citizen`, `back_lawcons`, `back_socialdispute` | back image URL |
| `tokenUrl(key)` | e.g. `worker_token`, `engineer_count`, `food`, `food_back`, `token_generator_home` | token URL |
| `tileUrl(key)` | e.g. `cookhouse`, `N01`, `F01`, `rim_strip_1`, `generator_tile` | tile URL |
| `boardUrl(key)` | e.g. `board_generator`, `board_panel_a`, `board_panel_a_back`, `board_round_track` | board URL |
| `modelUrl(key)` / `modelInfo(key)` | `coal`, `wood`, `workers`, `engineers`, `children`, `automatons`, `dreadnought`, `steam_core`, `steam_hub`, `steel`, `trees`, `leadership_marker`, `round_marker`, `model_1f2abb1e` | GLB URL, plus `extent`, `sourceExtent`, `textured`, `flipped`, `tris` |
| `audioUrl('theme')` | `theme` | mp3 URL |
| `pdfUrl('frostpunk_rulebook')` | `frostpunk_rulebook`, `frostpunk_rules_supplement` | PDF URL |

`manifest` exposes the raw records (`cards`, `tokens`, `tiles`, `boards`, `models`, `audio`, `pdfs`). Use it for listing. Use the accessors for lookups.

Records for sheet-cropped images carry `deck` and `idx`, the TTS deck id and row-major cell index the image came from.

`BASE` is taken from `import.meta.env.BASE_URL`, so URLs work under a sub-path deploy.

## Card id mapping

- Card id = `deckId * 100 + idx` in TTS. Faces are cropped from the deck's `FaceURL` sheet, row-major, at cell `idx`.
- Morning cards use deck 543 and the `idx` field of the morning data files (`M###`).
- Unique-back decks (552, 553, 557, 725) get `<id>_back`. Other decks share a back per family, `back_<family>`, cropped from the deck's `BackURL`.
- Map tiles use the `sheet` field (550/551) with their `idx`.

## Unresolved and skipped

- `meta.unresolved` is empty. Every card, token, tile, board and model resolves to a file.
- `meta.missingImageUrls` lists two steamusercontent URLs that the mod references but that are absent from the source assets. One is the Justice token/tile image (`7F89C5BAA2`). The corresponding keys are not emitted.
- `models`: `model_1f2abb1e` (TTS mesh suffix 1F2ABB1E) is an unnamed model with no nickname or description. Its shape is the Generator tower (tall, round top with spokes), so `apps/web/src/map/scene.ts` stands it in the Generator crater. This is identified by shape only, not by a name in the mod.
- `models` placed in the 3D map: `workers`, `engineers`, `children`, `automatons` (meeples), `wood`, `coal`, `steam_core` (resources), `trees`, `steam_hub` (building), `dreadnought` (laid along the scenario's dread tiles, sunk 55% so meeples on it stay readable) and `model_1f2abb1e` (Generator tower). Not placed in the 3D map: `steel`, `leadership_marker`, `round_marker`. The map has no 3D slot for them: steel is a supply-only resource, and the leader and round markers belong to the 2D round track and HUD.
- Skipped by default: the four advisor responsibility sheets (`advisor_foreman`, `advisor_social`, `advisor_health`, `advisor_generator`, about 14.7 MB). The digital game automates them. Run with `--all-pdfs` to ship them.

## Regenerating

1. Keep the raw TTS mod copy in `assets_src/` (the script's input; see its header).
2. `python -I tools/optimize_assets.py`. Add `--all-pdfs` to include the advisor sheets. `--verify` only validates existing outputs (GLB headers and accessors, manifest paths).
3. Check `apps/web/public/assets/manifest.json` `meta.counts` and `meta.unresolved`.
4. `node_modules/.bin/tsc --noEmit -p apps/web/tsconfig.json`. `manifest.ts` must typecheck.

Bump `VERSION` in the script when a change would alter output bytes for an unchanged source. This invalidates the cache.

## Provenance

- `assets_src/` is a byte-for-byte copy of the Tabletop Simulator mod folder `C:\Users\aston\Documents\My Games\Tabletop Simulator\Mods\`. SHA-1 check of every file against the source folder:
  - Audio: 1 of 1 identical (`Audio`).

- The outputs in `apps/web/public/assets/` come from these copies only. Nothing was downloaded from elsewhere.
